Project-2-CS-472

In this project, I built a Convolutional Neural Network (CNN) to classify images as either cats or dogs. The images were first resized to 64 × 64 so they would all have the same shape, and then the pixel values were normalized so the model could train more effectively. After training the CNN, the model reached a test accuracy of 67.76% and a test loss of 0.6010. This shows that the model was able to learn some useful patterns from the images, but it was not accurate enough to classify every image correctly.
Looking at the confusion matrix helped me understand the model’s performance more clearly. The model correctly classified 1972 cat images and 1416 dog images. At the same time, it misclassified 528 cats as dogs and 1084 dogs as cats. This means the model did a better job recognizing cat images than dog images. Even though the results were not perfect, they still show that the CNN learned important visual features from the dataset.
One of the main strengths of this model is that it used convolutional and pooling layers, which are much better for image data than a regular neural network that just flattens the images. CNNs can capture things like edges, textures, and shapes while keeping the spatial structure of the image. This made the CNN perform better than the earlier feedforward neural network approach I tried before. Another strength is that the model was simple enough to build and train without being too complicated, which made it a good choice for understanding the basics of deep learning for image classification.
At the same time, the model also had some limitations. First, I only used a subset of the dataset for training, so the model did not get to learn from all of the available cat and dog images. Second, the CNN architecture itself was fairly simple, with only two convolutional layers, so it may not have been strong enough to learn more detailed patterns in the data. Third, the model was only trained for five epochs, which may not have been enough time for it to fully improve. Another limitation is that I used the test set as validation data during training, which works for a class project but is not the best practice in a more professional machine learning workflow.
There are many ways that you could improve this project in the future. One way to improve it would be to train it on more images so the CNN could see a wider variety of cats and dogs. Another improvement would be to train for more epochs and experiment with different settings like batch size, number of filters, or layer sizes. I could also add techniques like dropout or data augmentation to help the model generalize better. A much stronger improvement would be to use transfer learning with a pre-trained model, which would probably give much better results on this kind of image classification problem.
Overall, I think this project was successful in showing how CNNs can be used for image classification. Even though the final accuracy was not extremely high, the model still performed better than a regular neural network and showed why CNNs are more suitable for image data. This project helped me better understand how deep learning models are designed, trained, and evaluated, as well as the challenges involved in improving their performance.
